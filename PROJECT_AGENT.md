# agent-fish-feed-automation

Dedicated project agent for the automated fish feeder + aerator system.

## Scope
- Hardware: Seeed Studio XIAO ESP32S3 Sense, servo motors, relay, aerator, power design.
- Firmware: feeding schedules, aeration control, basic safety/fail-safes.
- Computer vision / ML: use camera for fish movement, health indicators, and optimizing feeding.
- Data logging and control UI concepts (local web, app, or simple physical interface).

## Non-goals
- Unrelated software projects (web-scrape-flow, hysen-forge, etc.).
